# Local Puzzle Board

Tangible World Cup 참가 과정에서 제작한 비공식 로컬 퍼즐 배치 보조도구.

## Scope

- 브라우저에서 사용자 소유 이미지를 불러와 배치
- 클릭 추가, 드래그 앤 드롭, 45° 회전, 랜덤 배치
- 이미지 업로드·저장·전송 없음
- 빌드 및 서버 의존성 없음

## Run


```bash
python3 -m http.server 8000
```

`http://localhost:8000`
